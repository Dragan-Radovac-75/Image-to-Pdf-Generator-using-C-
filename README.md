# Image-to-Pdf-Generator-using-C#
Generates a Pdf from most images types (JPEG, TIFF, PNG, BMP, GIF)

A simple way to generate pdf files without dependencies and without a pdf printer. When generating reports as images, for example, using the System.Drawing library in .NET with Graphics and Bitmap classes, this code will use that Bitmap and generate a pdf without the requirement of saving to a file.
