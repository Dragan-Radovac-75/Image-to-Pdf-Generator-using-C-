# Image-to-Pdf-Generator-using-C#
Generates a pdf from most image types (JPEG, TIFF, PNG, BMP, GIF)

A simple way to generate pdf files without dependencies and without a pdf printer. When generating reports as images, for example, using the System.Drawing library in .NET with Graphics and Bitmap classes, this code will use that Bitmap and generate a pdf without the need to save the Bitmap to a file.

The generated pdf document can be found in \bin\Debug\net9.0-windows\ below the solution folder and is named 'document.pdf'
